# MiniTSDB 设计文档

创建时间：2026-05-24

## 概述

MiniTSDB 是一个面向工业 SIS（厂级监控信息系统）场景的轻量级时序数据库，单机部署，
通过 SQL 接口提供数据写入、查询和管理能力。

## 目标场景

- 电厂/煤场传统 SIS 数据采集
- 替代 PI（OSIsoft PI System）等传统实时数据库
- 典型部署规模：10万 ~ 30万测点（Tag）
- 采集频率：100ms ~ 5s，以 1s 为主

## 核心设计原则

1. **SQL 全接口** — 所有操作（写入、查询、管理）通过 SQL 完成
2. **单机优先** — 先做好单机，稳定后再考虑分布式
3. **冷热分层** — 最近 3 个月 SSD 热存，历史数据 HDD 冷存
4. **高压缩率** — Gorilla 算法，支持 2 年数据保留

## 存储引擎

- **MemTable**：每个 Tag 独立的环形缓冲，按 Tag 分组批量写入
- **SSTable**：按 Tag × 天分文件，内部分段存储
- **Gorilla 压缩**：Delta-of-delta 时间戳 + XOR 浮点值
- **Compaction**：后台自动合并小文件，冷数据迁移

## SQL 接口

参见 ast.h 中定义的 SQL 语法：
- INSERT INTO — 写入数据
- SELECT + LATEST — 实时查询
- SELECT + TIME_BUCKET — 聚合查询
- CREATE TAG — 注册测点
- CREATE ALARM — 报警规则

## 查询引擎

- **最新值缓存**：ConcurrentHashMap，所有 Tag 的最新值常驻内存
- **LATEST 查询**：直接命中缓存，微秒级返回
- **聚合查询**：流式读取 + 边读边聚合，不构建中间结果集

## 数据规模估算（20万点，Gorilla 压缩）

- 每秒写入：约 35 万条
- 每天存储：约 30 GB
- 热区 3 个月：约 2.7 TB（SSD）
- 冷区 2 年：约 22 TB（HDD）
